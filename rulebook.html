Family

Ring me for WhatsApp when it's from Mom.

Add this rule

Nothing opened? Get RingMeFor, or update it, then tap Add again.

Set it up in RingMeFor

  1. In RingMeFor, open WhatsApp from the Home screen. If it isn't there, tap Add Apps and add it: RingMeFor then shows how to add it to the RingMeFor shortcut.
  2. Tap Add a Rule, and name it Mom.
  3. Under People, add Mom.
  4. Tap Save.

On the free version, an app rings only for its first rule. Before you add this one, open the app's ready-made rule, Urgent, and tap Delete Rule.

Someone keeps trying

Ring me for Messages when the same person texts 3 times within 5 minutes.

Add this rule

Nothing opened? Get RingMeFor, or update it, then tap Add again.

Set it up in RingMeFor

  1. In RingMeFor, open Messages from the Home screen. If it isn't there, tap Add Apps and add it: RingMeFor then shows how to add it to the RingMeFor shortcut.
  2. Tap Add a Rule, and name it Keeps trying.
  3. Set Ring for to Every notification.
  4. Under Repeats, turn on Only when it comes again, then set it to 3 times and Within to 5 minutes, and leave From the same person on.
  5. Tap Save.

On the free version, an app rings only for its first rule. Before you add this one, open the app's ready-made rule, Urgent, and tap Delete Rule.

On call at night

Ring me for Slack when it says “@here” or “@channel”, every day from 10 PM to 7 AM, and ring again until I stop it. Pro

Add this rule

Nothing opened? Get RingMeFor, or update it, then tap Add again.

Set it up in RingMeFor

  1. In RingMeFor, open Slack from the Home screen. If it isn't there, tap Add Apps and add it: RingMeFor then shows how to add it to the RingMeFor shortcut.
  2. Tap Add a Rule, and name it On call at night.
  3. Under Words, add @here and @channel.
  4. Under When, turn on Only at certain times and days, then set From to 10 PM, Until to 7 AM and Days to Every day. Pro
  5. Turn on Ring again, below the Alarm settings. Pro
  6. Tap Save.
